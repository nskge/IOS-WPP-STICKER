# GIF Sticker WPP

Simple black-and-white page for turning an X/Twitter GIF post into a direct GIF preview.

## Usage

1. Copy an X/Twitter GIF post link.
2. Open the page and tap "paste".
3. Use "copy gif" for the preview or "copy link" for the direct link.
4. Use it on mobile to save or create a WhatsApp sticker.

Note: X/Twitter GIFs are usually MP4 under the hood.
